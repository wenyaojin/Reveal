# 实验设计与 AI 执行清单

每项任务独立记录 Git 提交、数据切分、权重、种子、命令、耗时与失败数。改模型和选参数用验证集，最终测试使用新来源或此前没有用于选型的病例。

| 任务 | 执行步骤 | 回填内容 |
|---|---|---|
| E01 复现五类基线 | 按 RUNBOOK 生成配准清单，复跑学习形变、项目平均形变及冻结底座 | 各类配对与排除计数、局部误差、关键点误差、出图失败原因 |
| E02 增加保护区 | 在验证集对比现有形变和新增眼球、唇部保护约束的形变。固定其余参数 | 保护区像素差、目标变化幅度、可见形变和失败类型 |
| E03 独立盲评 | 用脚本生成匿名左右对照；让评审独立填写可见性、同人、自然度和伪影位置，再解盲 | 各项目有效分母、各题通过率、原图对原图控制组结果 |
| E04 扩数据 | 核实配对身份、拍摄条件和可见变化方向。为肤质项目收集可比的同人随访 | 每项目独立人数、数据质量/拍摄差异、可归因变化、来源 |

可直接给执行 AI 的指令：

> 阅读本目录的 README、RUNBOOK 和 EXPERIMENTS。先完成 E01 的数据核查和形变基线，确认资产可用后运行冻结底座。记录命令、成功和失败数、每类指标及与历史结果的差异。产物写在 POSTOP_WORKSPACE。实验汇报给出可核验的本地路径。
