# 术后外观模拟实验

本目录记录 Reveal 图像编辑的独立研究实验。输入一张术前图和项目条件，输出原分辨率的局部外观模拟图。目标是让变化可辨，同时保留身份与真实皮肤质感。

## 2026-11-18 进度

HDA 五类共 639 对。6 对编号待核、2 对未通过配准，剩余 487/46/98 对用于训练、验证和内部测试。分组使用病例编号和跨类别感知哈希近重复聚类，独立身份仍待复核。

| 方法 | 目标关键点误差（双眼外眼角间距的百分比） | 优于原图 |
|---|---:|---:|
| 原图 | 2.99% | — |
| 冻结 FLUX | 2.76% | 62/98 |
| 共享 LoRA | 2.96% | 50/98 |
| 学习形变 | 2.67% | 63/98 |

LoRA 训练使用 FLUX.2-klein-base-4B、384 像素局部裁剪、BF16、rank 8、110 次更新，每步五类各取一例。出现过眉段变黑和脸缘块状色差。形变模型的训练和评估使用相同关键点检测器。独立自然度、可见性盲评尚无分数，单图自动选择项目也尚未训练。研究数据和权重沿用 HDA 使用条件。
